# Quorelis frontend

**Consensus has a price.** Vue 3 / Vite on Solana, with a dark on-chain consensus terminal.

The interface supports illustrative event-scenario discovery, a six-peer quorum readout, local practice positions, responsive navigation, and optional read-only SOL and configured outcome-share balance checks through an injected Solana provider. The configured YES market-asset mint is deployed on Testnet with 9 decimals and zero initial supply; prediction-market execution, settlement, and issuance remain unavailable.

Copy `.env.example` to `.env` and set `VITE_SOLANA_CLUSTER`, `VITE_SOLANA_RPC_URL`, and `VITE_SOLANA_EXPLORER_URL`. The public Testnet mint is configured in `VITE_TOKEN_MINT`. Never put a private key in a `VITE_` variable. `npm run deploy:testnet` verifies the existing mint idempotently; the signer is read only from the ignored workspace `key.txt`.

## Visual system

`public-active/` holds the shipped media, and `vite.config.js` serves that directory as the public root. All of it is generated by `twitter/rebrand_assets.py` from `twitter/brand.json`; edit the palette there and regenerate rather than hand-editing these files.

| Asset | Role |
| --- | --- |
| `quorelis-mark.svg` | Primary consensus-lattice mark (sidebar, avatar, cards) |
| `favicon.svg` | Reduced signal mark for small sizes |
| `favicon-64.png`, `icon-512.png` | Raster twins of the reduced mark |
| `quorelis-og.png` | 1200 x 630 social and Open Graph card |

The mark is a consensus lattice: six peer nodes on a closed ring, one spoke from each peer into a single bright quorum node, and the market signal crossing the lattice as an ascending stroke. Below roughly 48 px the lattice turns to mush, so the favicon uses a reduced variant with one signal stroke, one peer node, and one lime terminus.

Brand identity strings live in `src/config.js` (`BRAND_NAME`, `BRAND_SLUG`, `BRAND_TAGLINE`, `BRAND_MARK_URL`, `BRAND_DOMAIN`); document metadata lives in `index.html`. `website/a7104sol/` is a synchronized mirror — run `powershell -File scripts/sync-frontend.ps1` from the repository root after frontend changes.
